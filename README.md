# **Pénzügyi napló**

## **Mit is csinál?**

- A programunkban könnyen tudod kezelni a pénzügyeidet. 

- Dátumot is automatikusan elmenti minden könyvelésnél.

- Tranzakciókat is tudsz rögzíteni. 

- Tranzakciók keresése is lehetséges és könnyű is

- Tudsz emlékeztetőket is beálítani.

----

## **Első indításnál:**
- Bekérünk egy **kezdeti egyenleget** és egy **pénznemet**.

- Az **egyenlegedet** bármikor letudod kérdezni.

- Többször nem fogjuk bekérni ezeket, <mark>az egyenleged automatikusan változik minden bevétel/kiadásnál.</mark>

----

## **Egyenleg megtekintése**

- Itt láthatod azt az egyenleget, amit az első indításnál beirtál, és ugyanúgy változik az összes kiadással és bevétellel, így mindig az aktuális egyenlegedet látod.
----

## **Tranzakció rögzítése**

- Itt tudod rögzíteni a tranzakcióidat.

- Itt két opció küzöl tudsz választani, hogy bevétel vagy kiadás legyen.

- Dátumot automatikusan a operációs rendszer idejét rögzíti.
----

## **Keresés funkció**

- Tudsz pontos dátum alapján is <br> (pl: 2026-11-24-én az össszes tranzakció)

- Tudsz két dátum között <br> (pl: 2026-11-23 és 2026-11-25 között.)

- Tudsz tranzakció neve alapján is <br> (pl: 'Iphone Duo' vagy 'kutyatáp')
----

## **Emlékeztetők rögzítése**

- Tudsz emlékeztetőket létrehozni, ami aktuálisan emlékeztet is.

- A program indulásánál megnézi a mai dátumot és ha van emlékeztető akkor ki is írja.

- Indokot is lehet irni, sőt a program kér is indokot hogy mire kell az emlékeztető.
----

## **Program bezárása**

- Nevéből adodóan bezárja a programot.
