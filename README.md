# **Pénzügyi napló**
## **Mit is csinál?**
- A programunkban könnyen tudod kezelni a pénzügyeidet. 

- Dátumot is automatikusan elmenti minden könyvelésnél.

- Tranzakciókat tudsz rőgzíteni. 

- Tranzakciók keresése is lehetséges és könnyű is

- Tudsz emlékeztetőket is beálítani.

----

## **Első indításnál:**
- Bekérünk egy kezdeti egyenleget és egy pénznemet.

- Az egyenlegedet bármikor letudod kérdezni.

- Többször nem fogjuk bekérni ezeket, az egyenleged automatikusan változik minden bevétel/kiadásnál.

----

## **Keresés funkció**

- Tudsz pontos dátum alapján is keresni <br> (pl: 2026-11-5-én az össszes tranzakció)

- Tudsz két dátum között keresni <br> (pl: 2026-11-3 és 2026-11-5 között.)

- Tudsz termék neve alapján
